Guia de uso por pasos
1. Activar el programa y Registrar un empleado: Indicar si el empleado es enfermero, médico o administrativo. Luego, ingresar la identificación del empleado, el nombre, el salario base y los demás datos que solicite el programa.
2. listar empleados:Muestra la lista completa de empleados registrados. También permite importar empleados utilizando el mismo formato de texto. Por ejemplo: Medico|1214|gaboloco|13293.00|general|1.00|1.00|1.00|2.00  Los datos deben estar separados por el símbolo |. Después de la especialidad, se deben ingresar las horas extra, la bonificación nocturna, la bonificación por guardia y, por último, las deducciones.
3. Registrar montos salariales del empleado rellenar los campos con la informacion necesaria.
4. Generar comprobante de pago del empleado.
5. Guardar datos en un archivo.
6.  Registrar departamentos.
7. pon un codigo para el departamento
8. Asignar un nombre al departamento.
9. Agregar puestos al departamento.El programa pregunta si se desea agregar un puesto al departamento. Si la respuesta es afirmativa, se debe ingresar el nombre del puesto.
10. Listar departamentos. Finalmente, permite visualizar los departamentos registrados y los puestos disponibles en cada uno.
